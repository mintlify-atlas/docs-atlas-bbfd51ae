Porfolio & Blog CMS is a self-hosted personal website and content management system built with **ASP.NET Core 10** and **Blazor Server**. It implements a full Clean Architecture stack—Domain, Application, Infrastructure, API, and UI layers—giving you a maintainable, testable foundation you can extend with blog posts, portfolio projects, and custom pages.

## Get up and running

<Steps>
  <Step title="Clone and restore">
    Clone the repository and restore .NET dependencies.
    ```bash
    git clone https://github.com/Andrespeerez/porfolio-blog.git
    cd porfolio-blog
    dotnet restore
    ```
  </Step>
  <Step title="Apply database migrations">
    Run EF Core migrations to create the SQLite database.
    ```bash
    dotnet ef database update
    ```
  </Step>
  <Step title="Run the application">
    Start the Blazor Server app. The dev admin user is seeded automatically.
    ```bash
    dotnet run
    ```
  </Step>
  <Step title="Log in to the admin panel">
    Open your browser to `http://localhost:5058` and navigate to `/login`. Use the seeded credentials from `appsettings.Development.json` to sign in and access `/admin`.
  </Step>
</Steps>

<Note>
  The admin user seeder only runs in the **Development** environment. See [Seeding](/seeding) for details on configuring seed credentials.
</Note>
